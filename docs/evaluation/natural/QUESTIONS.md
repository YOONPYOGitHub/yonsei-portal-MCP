# 자연스러운 질문 대화

각 대화는 서로 독립적입니다. 한 대화 안에서는 질문을 차례로 보내고, 실제로 받은 답변을 다음 질문의 대화 기록에 넣습니다. 미리 작성한 답변은 없습니다. 첫 번째 항목이나 그거라는 표현은 실제 앞선 답변을 가리킵니다. 앞선 답변에 목록이 없으면 가상의 목록을 덧붙이지 않습니다.
